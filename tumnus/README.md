## Project Overview

**Tumnus** is a web application built with [Next.js](https://nextjs.org/) and [React](https://reactjs.org/), featuring modern UI components from [Ant Design](https://ant.design/). It uses [TypeScript](https://www.typescriptlang.org/) for type safety and provides a smooth development experience. This project is designed for web developers looking to create scalable and stylish web applications.

## Installation

To run this module in development mode, you should have yarn installed.

## `install yarn`

## Available Scripts

In the project directory, you can run the following scripts:

-  **dev**: Start the development server with debugging enabled.

### `yarn dev`

-  **build**: Build the production-ready application.

### `yarn build`

-  **start**: Start the production server.

### `yarn start`

-  **lint**: Run the linting process.

### `yarn lint`

## Pre-Development Setup

Before running the `dev` script, you should generate Ant Design CSS files. Run the following command:

### `yarn predev`

## Pre-Build Setup

Before running the `build` script, you should generate Ant Design CSS files for production. Run the following command:

### `yarn prebuild`
